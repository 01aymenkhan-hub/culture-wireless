## 1. Fetch Hosted Page Details

When the user is redirected to:

```text
/order-received?hostedpage_id=...
```

Read the `hostedpage_id` from the URL.

Use it to call the Zoho **Get Hosted Page API** and retrieve the complete order details.

Use the existing Zoho authentication flow (`zoho.js`) for generating the access token.

---

## 2. Display Complete Order Details

Populate the Order Received page dynamically using the Hosted Page API response.

Display information such as:

* Customer Name
* Email
* Service Address
* Selected Service
* Purchased Plan
* Plan Price
* Selected Add-ons (if any)
* Add-on Price
* Total Price
* Subscription Details (if available)
* Order/Subscription Reference (if available)

Do not hardcode any values.

Everything should come from the Hosted Page API response.

---

## 3. Create Zoho Desk Ticket

zoho ticket api url https://desk.zoho.com/api/v1/tickets

After successfully retrieving the Hosted Page details, automatically create a Zoho Desk ticket.

Use the Hosted Page response as the source of truth for the ticket data.

Populate the ticket body with all relevant customer and order information available in the Hosted Page response, including:

* Customer Name
* Email
* Service Address
* Selected Service
* Purchased Plan
* Selected Add-ons
* Pricing
* Hosted Page ID
* Any other useful order/subscription details returned by the API

Do not rebuild this data from Context or Local Storage. Use the Hosted Page API response.
